# Provisionamento Automático com Terraform e Google Cloud

## 1. Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de
Gerência de Configurações e Automação.

O objetivo é demonstrar o uso do Terraform como ferramenta de
Infraestrutura como Código (IaC), utilizando a abordagem declarativa
para definir recursos da Google Cloud.

A atividade permite a elaboração dos códigos Terraform sem a
necessidade de realizar a conexão ou o provisionamento efetivo
na Google Cloud.

## 2. Tecnologias utilizadas

- Terraform
- Google Cloud Platform (GCP)
- HashiCorp Configuration Language (HCL)
- Git
- GitHub
